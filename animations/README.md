# Video library

The radio-client lists the regular media files in this directory and the
subdirectories that contain frames. Use `RADIO_VIDEO_DIR` to point to another
library; only the specified directory and its immediate subdirectories are
scanned (symlinks are ignored).

Supported input files are:

- `.caca`: native libcaca canvas, including embedded multiple frames.
- `.ansi` and `.ans`: ANSI-coloured artwork; modern UTF-8 files can contain
  multiple frames separated by form-feed followed by newline (`\\f\\n`).
  CP437 `.ans` files are also accepted as legacy ANSI artwork.
- `.txt`: UTF-8 text; `.asc`: legacy plain-text artwork.
- A subdirectory containing `0000.ansi`, `0001.ansi`, ... (or any supported
  extension) is played in lexicographical filename order. Use zero-padding.

libcaca handles decoding and colours; ncursesw renders the decoded characters
without invoking another terminal display driver. Video starts at 10 FPS and
loops indefinitely. Optional FPS sidecars allow 1 through 60 FPS:

- `city-traffic.ansi.fps` (plain text with `10`) next to a standalone file.
- `animation.fps` (plain text with `10`) inside a frame directory.

The display uses the dimensions embedded in the media; no resizing or
resampling of character art occurs. Its minimum size is 100x30 characters.
A larger file needs a terminal at least as large as the file's widest/tallest
frame; smaller files are centred on the display.

`city-traffic.ansi` is a 10-second, 100x30, 10-FPS example, generated by
`tools/create-traffic-demo.py` (Python 3 standard library only).

Durdraw's native `.dur` is not a libcaca format. Export it to ANSI or to a
sequence of ANSI frames before placing it here.
